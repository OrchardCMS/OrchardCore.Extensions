## Features

### Share Draft Content

Allows sharing of draft content items via a unique link. Its upstream feature ID is `OrchardCoreContrib.Contents.ShareDraftContent`, and it is categorized as Contents. It depends on `OrchardCore.Contents`, so Orchard Core enables that dependency when this feature is enabled.
