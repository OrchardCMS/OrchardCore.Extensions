Provides the SMS Omnichannel Automation module for Orchard Core.

## Features

### SMS Omnichannel Automation

Handles automated omnichannel activities through the configured Orchard Core SMS provider. Its manifest-backed feature ID is `CrestApps.OrchardCore.Omnichannel.Sms`, and it is categorized as Contact Center. It depends on `CrestApps.OrchardCore.AI`, `CrestApps.OrchardCore.AI.Chat.Core`, `CrestApps.OrchardCore.Omnichannel.Managements`, and `OrchardCore.Sms`, so Orchard Core enables those dependencies when this feature is enabled. This description is based on the CrestApps manifest and documentation; in Orchard Core, feature entries are shown in the feature management UI with their description, category, and dependencies.
