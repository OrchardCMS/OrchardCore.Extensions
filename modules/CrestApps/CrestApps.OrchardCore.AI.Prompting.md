## Features

### AI Prompt Templates

Provides reusable template management with feature-aware discovery, Liquid-based rendering, and prompt selection UI for AI Profiles and Chat Interactions. Its manifest-backed feature ID is `CrestApps.OrchardCore.AI.Prompting`, and it is categorized as Artificial Intelligence. It depends on `CrestApps.OrchardCore.AI`, so Orchard Core enables that dependency when this feature is enabled.
