Enables the ability to send SMS messages through Azure Communication Services (ACS).

## Features

### Azure Communication Services SMS

Enables the ability to send SMS messages through Azure Communication Services (ACS). Its manifest-backed feature ID is `OrchardCore.Sms.Azure`, and it is categorized as Communication. It depends on `OrchardCore.Sms`, so Orchard Core enables that dependency when this feature is enabled. This description is based on the Orchard Core manifest and official documentation; in Orchard Core, feature entries are shown in the feature management UI with their description, category, and dependencies.
