## Features

### Search

Provides frontend search capabilities against indexes. Its manifest-backed feature ID is `OrchardCore.Search`, and it is categorized as Search. It depends on `OrchardCore.Indexing`, so Orchard Core enables that dependency when this feature is enabled.
