## Features

### Custom Settings

The custom settings modules enables content types to become custom site settings. Its manifest-backed feature ID is `OrchardCore.CustomSettings`, and it is categorized as Settings. It depends on `OrchardCore.Contents`, so Orchard Core enables that dependency when this feature is enabled. This description is based on the Orchard Core manifest and official documentation; in Orchard Core, feature entries are shown in the feature management UI with their description, category, and dependencies.
