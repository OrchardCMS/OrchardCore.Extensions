Allows to organize widgets in an Admin Dashboard.

## Features

### Admin Dashboard

Allows to organize widgets in an Admin Dashboard. Its manifest-backed feature ID is `OrchardCore.AdminDashboard`, and it is categorized as Content Management. It depends on `OrchardCore.Admin`, `OrchardCore.Html`, `OrchardCore.Title`, and `OrchardCore.Recipes.Core`, so Orchard Core enables those dependencies when this feature is enabled. This description is based on the Orchard Core manifest and official documentation; in Orchard Core, feature entries are shown in the feature management UI with their description, category, and dependencies.
