## Features

### Spatial

This feature provides the ability to provide spatial locations to content items. Its manifest-backed feature ID is `OrchardCore.Spatial`, and it is categorized as Content Management. It depends on `OrchardCore.ContentTypes`, and `OrchardCore.Lucene`, so Orchard Core enables those dependencies when this feature is enabled. This description is based on the Orchard Core manifest and official documentation; in Orchard Core, feature entries are shown in the feature management UI with their description, category, and dependencies.
