## Features

### Forms

Provides widgets and activities to implement forms. Its manifest-backed feature ID is `OrchardCore.Forms`, and it is categorized as Content. It depends on `OrchardCore.Widgets`, and `OrchardCore.Flows`, so Orchard Core enables those dependencies when this feature is enabled. This description is based on the Orchard Core manifest and official documentation; in Orchard Core, feature entries are shown in the feature management UI with their description, category, and dependencies.
