## Features

### Menu

The Menu module provides menu management features. Its manifest-backed feature ID is `OrchardCore.Menu`, and it is categorized as Navigation. It depends on `OrchardCore.Contents`, `OrchardCore.Title`, `OrchardCore.Alias`, and `OrchardCore.Recipes.Core`, so Orchard Core enables those dependencies when this feature is enabled. This description is based on the Orchard Core manifest and official documentation; in Orchard Core, feature entries are shown in the feature management UI with their description, category, and dependencies.
