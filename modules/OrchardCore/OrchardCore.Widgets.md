## Features

### Widgets

Provides a part allowing content items to render Widgets in theme zones. Its manifest-backed feature ID is `OrchardCore.Widgets`, and it is categorized as Content. It depends on `OrchardCore.ContentTypes`, so Orchard Core enables that dependency when this feature is enabled. This description is based on the Orchard Core manifest and official documentation; in Orchard Core, feature entries are shown in the feature management UI with their description, category, and dependencies.
