Enables users to render Widgets across pages of the site based on conditions.

## Features

### Layers

Enables users to render Widgets across pages of the site based on conditions. Its manifest-backed feature ID is `OrchardCore.Layers`, and it is categorized as Content. It depends on `OrchardCore.Widgets`, `OrchardCore.Scripting`, and `OrchardCore.Rules`, so Orchard Core enables those dependencies when this feature is enabled. This description is based on the Orchard Core manifest and official documentation; in Orchard Core, feature entries are shown in the feature management UI with their description, category, and dependencies.
