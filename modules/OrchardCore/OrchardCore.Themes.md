## Features

### Themes

The Themes modules allows you to specify the Front and the Admin theme. Its manifest-backed feature ID is `OrchardCore.Themes`, and it is categorized as Theming. It depends on `OrchardCore.Admin`, so Orchard Core enables that dependency when this feature is enabled. This description is based on the Orchard Core manifest and official documentation; in Orchard Core, feature entries are shown in the feature management UI with their description, category, and dependencies.
