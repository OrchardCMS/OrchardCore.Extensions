## Features

### Remote Deployment

Provide the ability to export and import to and from a remote server. Its manifest-backed feature ID is `OrchardCore.Deployment.Remote`, and it is categorized as Deployment. It depends on `OrchardCore.Deployment`, so Orchard Core enables that dependency when this feature is enabled.
