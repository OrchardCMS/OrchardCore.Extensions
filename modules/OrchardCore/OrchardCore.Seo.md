## Features

### SEO

Provides SEO meta features. Its manifest-backed feature ID is `OrchardCore.Seo`, and it is categorized as Content Management. It depends on `OrchardCore.Contents`, `OrchardCore.Recipes.Core`, `OrchardCore.Media`, and `OrchardCore.Shortcodes`, so Orchard Core enables those dependencies when this feature is enabled. This description is based on the Orchard Core manifest and official documentation; in Orchard Core, feature entries are shown in the feature management UI with their description, category, and dependencies.
