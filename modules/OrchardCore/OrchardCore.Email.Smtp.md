## Features

### SMTP Email Provider

Provides an email service provider leveraging Simple Mail Transfer Protocol (SMTP). Its manifest-backed feature ID is `OrchardCore.Email.Smtp`, and it is categorized as Communication. It depends on `OrchardCore.Email`, so Orchard Core enables that dependency when this feature is enabled. This description is based on the Orchard Core manifest and official documentation; in Orchard Core, feature entries are shown in the feature management UI with their description, category, and dependencies.
