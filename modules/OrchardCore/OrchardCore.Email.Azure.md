### Azure Communication Services Email

Provides email service providers leveraging Azure Communication Services (ACS). Its manifest-backed feature ID is `OrchardCore.Email.Azure`, and it is categorized as Communication. It depends on `OrchardCore.Email`, so Orchard Core enables that dependency when this feature is enabled.
